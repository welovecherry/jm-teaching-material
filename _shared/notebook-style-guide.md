# 주피터 교안 스타일 가이드 (전 강의 공통)

> 노트북(.ipynb) 교안을 만들 때 **항상 이 규칙을 따른다.** 강사(정민홍)와 합의된 스타일이며,
> 새 강의·새 세션에서도 동일하게 적용한다. (근거 샘플: `26-09-.../03-samples/day01-2교시-파이썬기초-v2.ipynb`)

## 1. 큰 원칙
- **최대한 쉬운 말투 · 자세하게 · 가독성 우선.** 긴 설명은 짧은 문단·불릿·콜아웃으로 쪼갠다.
- 한 셀에 개념 하나. 구조: **A(강의 흐름) + C(워크북)** 혼합.

## 2. 말투
- 문장은 **`~습니다`** 체. `~어요/~죠` 지양.
- 명사형(`~하기`, `~함`)을 적절히 섞어 간결하게.

## 3. 이모지 — 딱 5종만 반복 (셀 종류 표시용)
| 표시 | 뜻 |
|------|-----|
| 📖 | 개념(읽기) |
| 💻 | 따라치기(그대로 실행) |
| ✍️ | 직접(값 바꾸기·작성) |
| ✅ | 결과(성공 예상 출력)·정답 |
| ❓ | 면접 질문 |

- 위 5개 외 장식용 이모지 금지. **구조 헤더(표지·목차·학습목표·요약·예고)는 이모지 없이 숫자**(`## 1.`, `## 2.`)로.
- 주의·경고는 이모지 대신 `> **주의:**` 볼드 콜아웃으로.

## 4. 코드 규칙
- **코드·문자열 값은 모두 영어.** (예: `customer_name = "acme"`, 출력도 `f"[{name}] fail={n}"`)
- **주석만 한국어.** 각 줄에 "왜/무엇" 주석을 빠짐없이.
- 셀은 **하나씩 실행**하게 잘게 나눈다(`&&`식 몰아치기 금지).
- 매 `💻따라치기` 코드 다음에 **`✅ 이렇게 나오면 성공` 예상 출력**을 반드시 붙이고,
  생성 후 **실제로 실행해 출력이 일치하는지 검증**한다.
- 개념은 **쉬운 것부터 단계적으로**(예: f-string ①→⑤), 따라치기 예제를 넉넉히(개념당 여러 칸).

## 5. "왜 이렇게 쓰지?" 궁금증
- 학생이 품을 법한 질문을 개념마다 1개씩 **`> **왜 ...?**` 볼드 blockquote**로 미리 해소.

## 6. ❓ 면접 질문 (섹션당 1개)
- 그 주제에서 **가장 핵심적인 면접 단골 질문**. 지엽적 금지.
- **반드시 '오늘 배운 범위 안'에서 답할 수 있어야 한다.** 범위를 넘으면 그 사실을 명시해
  수강생이 좌절하지 않게 한다. 질문의 답 근거를 **개념 설명에 자연스럽게 미리 녹인다.**
- 블록 구조: 질문 → `✍️ 스스로 답` → `✍️ 내 말로 한 줄 요약` → **모범답안(접기, `<details>`)**.
- **모범답안은 작성자(AI)가 초안 작성**하고 `*(모범답안 초안 — 강사 검토 후 확정)*` 표시.
- 프롬프트 예시는 넣지 않는다(학생이 알아서 AI 활용). 활용 안내만 노트북 앞부분에 한 번.

## 7. 마무리
- **오늘 요약**(번호 목록) → **종합 퀴즈(객관식, 정답 접기)** → **다음 시간 예고**.

## 8. 파일명·버전
- 파일명: `dayNN-N교시-주제-vN.ipynb` (하이픈 통일). 날짜는 파일명 대신 **표지 셀**에
  `만든 날짜 · 버전`으로 표기.
- 버전: **승인 전**에는 같은 vN을 개선해 덮어씀. **승인된 vN을 개정**할 때만 v(N+1)로 올림.
  (강사가 명시적으로 새 버전을 요청하면 그에 따름.)

## 9. 생성 방식
- 노트북은 **파이썬 생성 스크립트**(`md()/code()` 헬퍼)로 찍어낸다 → 5박자 리듬이 일정하게 유지.
  스크립트는 같은 폴더에 `dayNN-N교시-build.py` 로 보관(재생성 가능).
