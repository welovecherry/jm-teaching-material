# 실습 · 과다권한 탐지 스크립트 완성 (총 120분)

!!! note "자리표시 — 뼈대만 (강사가 직접 채웁니다)"
    실습 베이스라인 코드·상세 문제는 강사가 직접 작성합니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** 미사용·부서불일치·예외만료 세 신호로 과다권한 후보를 탐지하고, 종합 점검 리포트를 생성한다. 특히 경계값(89·90·91일)으로 부등호를 검증한다.

## 진행 단계 (상세교안 기준)

1. `access_control/overprivilege.py`에 `detect_unused_permissions(user_roles, access_logs, days=90)`을 구현한다
2. 로그가 없는 사용자(한 번도 안 씀)를 별도 처리한다(`max([])` 에러 방지)
3. `detect_dept_mismatch(user_dept, role_dept, user_roles)`를 구현한다(`owner_dept and`로 공통권한 오탐 방지)
4. Day1의 `is_exception_valid()`를 import해 만료 예외를 색출한다
5. `generate_review_report()`로 세 결과 + 총 건수를 한 딕셔너리로 묶는다
6. 경계값 테스트(89·90·91일)와 오탐 케이스(공통권한)를 `day03_test_result.md`에 정리한다

**산출물:** `access_control/overprivilege.py`, `config/access_logs.json`

## (작성 예정) 강사 예습 포인트

- 강사가 **먼저** `timedelta(days=90)`로 '딱 90일째' 로그를 만들어, `>`↔`>=` 결과가 뒤집히는 걸 직접 확인(강의2 ✍️ 블록과 연결)
- 학생이 자주 막히는 지점 기록:
  - 로그 없는 사용자에서 `max([])` 에러
  - `min()`을 써서 첫 사용일로 판정(오탐)
  - `owner_dept and` 빠뜨려 전사 공통권한을 오탐
  - `.days`를 안 붙이고 `timedelta`끼리 `>` 숫자와 비교하려다 실패
- 강의 중 ✍️ 손코딩과 연결: 경계값 실험을 실습에서 정식 테스트로 문서화

## 평가 기준 (상세교안)

- 세 탐지 신호가 각각 정확히 후보를 색출하는가
- 경계값(90일째)에서 정책 문장과 부등호가 일치하는가
- 로그 없음·공통권한 등 예외 상황에서 오탐/에러가 없는가
