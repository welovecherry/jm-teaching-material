# 3과목 Day 5 · 개요 — 권한 점검 체크리스트 & 결과 리포트 자동화·통합

!!! note "이 Day 사용법"
    Day 1~4에서 만든 함수들(RBAC·정책·요청승인·탐지·회수·조건)이 흩어져 있습니다. Day 5는 이들을 **하나의 `access_control` 모듈로 묶고**, 매주 자동 생성되는 **점검 리포트**를 완성하며, 1과목 AI Agent가 호출할 수 있게 **연동**하는 통합의 날입니다.

> **오늘 한 문장:** 1~4일차 산출물을 `weekly_report.py` 하나로 오케스트레이션해 **주간 접근통제 리포트**를 자동 생성하고, 핵심 함수를 1과목 `tool_router`에 등록해 캡스톤 모듈을 완성합니다.
> **왜 배우나:** 개별 함수가 아무리 좋아도 '따로 놀면' 실무에 못 씁니다. 오늘은 그것들을 엮어 "매주 월요일 아침, 보안팀장 책상에 자동으로 올라오는 리포트"를 만듭니다. 이것이 3과목 캡스톤 산출물의 완성본입니다.
