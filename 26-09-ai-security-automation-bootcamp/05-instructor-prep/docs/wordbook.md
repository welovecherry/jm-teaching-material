# 🔁 복습하기

내가 **⭐ 담은 용어**와 **❌ 틀린 퀴즈**를 한 곳에서 복습합니다.
과목·Day 상관없이 모이고, 브라우저에 저장되어 **새로고침·재방문해도 유지**됩니다.

## ⭐ 단어장

각 강의 상단 **"이 교시에 나오는 어려운 용어"** 표에서 ⭐를 누른 용어가 여기 모입니다.

!!! tip "사용법"

    - **담기:** 강의의 용어 표 맨 앞 ⭐ 체크박스 클릭
    - **빼기:** 오른쪽 `✕`, 또는 원래 표에서 체크 해제
    - **메모:** 메모 칸에 입력하면 **타이핑 즉시 저장**
    - **복습:** 🔁 복습 모드로 뜻·비유를 가린 뒤 줄을 클릭해 정답 공개

## ❌ 틀린 퀴즈 다시 풀기

강의의 퀴즈를 풀다 **틀린 문제**가 여기에 자동으로 모입니다. 다시 풀어 **맞히면 목록에서 빠집니다.**

<div id="review-wrong-root"></div>

!!! note "알아두기"
    저장 위치가 **이 브라우저**라서, 다른 컴퓨터에서는 보이지 않습니다.
