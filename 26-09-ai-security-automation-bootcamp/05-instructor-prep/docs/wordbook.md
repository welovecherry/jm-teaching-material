# ⭐ 내 단어장

각 강의 상단의 **"이 교시에 나오는 어려운 용어"** 표에서 **⭐를 체크한 용어**가 여기에 모입니다.
과목·Day 상관없이 **한 곳에 누적**되고, 브라우저에 저장되어 **새로고침·재방문해도 유지**됩니다.

!!! tip "사용법"

    - **담기:** 강의의 용어 표에서 맨 앞 ⭐ 체크박스를 클릭
    - **빼기:** 여기서 오른쪽 `✕`를 누르거나, 원래 표에서 체크 해제
    - **메모:** 메모 칸에 입력하면 **타이핑 즉시 저장**됩니다
    - **복습 모드:** 뜻·비유를 가린 뒤, 스스로 떠올리고 **줄을 클릭해 정답 공개**

<div id="wordbook-root"></div>

!!! note "알아두기"
    저장 위치가 **이 브라우저**라서, 다른 컴퓨터에서는 보이지 않습니다.
    (여러 기기에서 쓰고 싶으면 내보내기/가져오기 기능을 추가할 수 있습니다.)
