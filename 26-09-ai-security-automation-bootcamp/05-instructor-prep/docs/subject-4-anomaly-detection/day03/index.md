# 4과목 Day 3 · 개요 — 비인가접근·SaaS이상·악성행위 탐지 & 상관분석

!!! note "이 Day 사용법"
    Day 2가 "단일 신호 하나로 이상을 잡는" 룰이었다면, Day 3은 **여러 신호를 종합**합니다. 개별 탐지(비인가·SaaS·IOC)를 **위험점수로 합산**하고, 흩어진 이벤트를 시간순으로 **이어 하나의 공격 시나리오로 재구성(상관분석)** 합니다.

> **오늘 한 문장:** 비인가 접근·SaaS 이상·IOC 매칭을 각각 탐지해 **가중치 기반 위험점수**로 합치고, 시간 윈도우 **체이닝**으로 "로그인 실패→성공→비인가→유출" 같은 공격 흐름을 잡아냅니다.
> **왜 배우나:** 실제 공격은 한 방이 아니라 여러 단계로 이어집니다(킬체인). 단일 이벤트만 보면 놓치는 것을 상관분석이 잡습니다. 오늘 만든 위험점수·상관분석이 Day5 최종 파이프라인의 판단 핵심이 됩니다.
