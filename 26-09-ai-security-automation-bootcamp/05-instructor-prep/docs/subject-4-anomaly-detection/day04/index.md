# 4과목 Day 4 · 개요 — 오탐·미탐 검토 & 탐지룰 튜닝

!!! note "이 Day 사용법"
    Day 2~3에서 탐지 룰을 만들었다면, Day 4는 **"그 룰이 얼마나 정확한가"를 숫자로 측정**하고 개선합니다. 지금까지 감으로 말하던 '임계값 시소'를 **정밀도·재현율** 공식으로 정량화하는 날입니다.

> **오늘 한 문장:** 오탐(정상을 이상으로)·미탐(이상을 놓침)을 혼동행렬로 정리하고, **정밀도·재현율**로 탐지 성능을 측정한 뒤, 예외 조건·임계값 조정으로 룰을 **튜닝**해 성능을 개선합니다.
> **왜 배우나:** "탐지된다"와 "정확히 탐지된다"는 다릅니다. 측정 없는 개선은 없습니다. 오늘 배우는 성능지표와 튜닝 사이클이 실무 관제의 핵심 역량이고, "재현율 우선" 전략이 5과목 SOAR의 승인 게이트로 이어집니다.

- [ ] 정밀도·재현율의 공식과 트레이드오프를 설명한다
- [ ] 초기 탐지에서 왜 재현율을 우선하는지 안다
