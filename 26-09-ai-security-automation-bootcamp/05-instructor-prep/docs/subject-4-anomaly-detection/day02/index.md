# 4과목 Day 2 · 개요 — 베이스라인 & 이벤트 분류 & 로그인·트래픽 탐지 룰

!!! note "이 Day 사용법"
    Day 1에서 로그를 깨끗한 이벤트로 정규화했다면, Day 2는 그 이벤트에서 **"이상한 것을 골라내는 첫 탐지 룰"** 을 만듭니다. 핵심 개념은 **베이스라인(평소 패턴)** 과 **이동평균(추세 판단)** 입니다.

> **오늘 한 문장:** "무엇이 정상인가"를 통계로 정의한 **베이스라인**을 세우고, 이벤트를 유형별로 **분류(registry 패턴)** 한 뒤, 로그인 무차별 대입(brute-force)과 트래픽 급증을 탐지하는 룰을 구현합니다.
> **왜 배우나:** Day1이 데이터 준비였다면 오늘부터 진짜 '탐지'입니다. 여기서 만든 탐지 함수들이 Day3(고급 탐지)·Day4(튜닝)의 재료가 되고, 임계값을 config로 빼는 습관이 실무 운영의 기본이 됩니다.

## 오늘의 최종 목표 (Day 2를 마치면)
- [ ] 베이스라인이 왜 이상 판단의 전제인지 설명한다
- [ ] 통계 기반(평균·표준편차)과 규칙 기반 베이스라인을 비교한다
- [ ] 5대 관제 이벤트 유형과 로그 소스를 짝짓는다
- [ ] `classifier_registry` 패턴으로 여러 판단 함수를 등록·순회한다
- [ ] `detect_bruteforce()`로 로그인 실패 급증을 탐지한다
- [ ] `rolling()` 이동평균으로 트래픽 급증을 탐지하고, window 크기의 트레이드오프를 안다
