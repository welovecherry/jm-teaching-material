# 4과목 Day 5 · 개요 — AI 이벤트 요약·우선순위 분류 & 전체 통합·발표

!!! note "이 Day 사용법"
    Day 1~4에서 만든 조각(정규화·분류·탐지·상관분석·튜닝)을 **하나의 파이프라인으로 통합**하고, high 우선순위 이벤트를 **1과목 LLM 요약**으로 사람이 읽기 좋게 만들며, 1과목 `tool_router`에 등록해 캡스톤 '초동대응봇'의 핵심을 완성하는 날입니다.

> **오늘 한 문장:** 원본 로그 입력부터 정규화→탐지→위험점수→우선순위→AI 요약까지 이어지는 `run_anomaly_pipeline()`을 완성하고, 핵심 함수를 AI Agent의 도구로 등록합니다.
> **왜 배우나:** 개별 탐지가 아무리 좋아도 '따로 놀면' 실무에 못 씁니다. 오늘 통합으로 "로그를 넣으면 우선순위별 요약 리포트가 나오는" 완성형 파이프라인이 만들어지고, 이것이 4과목 캡스톤 산출물이자 5과목 SOAR의 입력이 됩니다.

## 오늘의 최종 목표 (Day 5를 마치면)
- [ ] 1~4일차 파이프라인 흐름과 1과목 스킬 재사용을 설명한다
- [ ] 탐지 이벤트를 1과목 LLM 요약에 연동하는 방식을 안다
- [ ] 우선순위 = f(위험점수, 상관분석, 자산중요도)를 설계한다
- [ ] 자산 중요도를 우선순위에 넣는 이유를 안다
- [ ] `run_anomaly_pipeline()` 오케스트레이션을 구성한다
- [ ] 핵심 함수를 `tool_router`에 등록해 AI Agent 도구로 만든다
