# 실습 · 망 구성도 작성 및 품질지표 진단 리포트 (총 120분)

!!! note "자리표시 — 뼈대만 (강사가 직접 채웁니다)"
    실습은 강사가 먼저 해보고 함정을 기록하는 성격입니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** 가상 A사 환경의 망 구성도를 작성하고, 품질지표를 실측해 SaaS 접속 지연 진단 리포트를 완성한다.

## 진행 단계 (상세교안 기준)
1. 가상 A사 시나리오(본사·지사·DMZ 웹서버·내부 DB·SaaS 사용 현황) 문서 확인
2. draw.io(또는 손그림)로 인터넷–외부방화벽–DMZ–내부방화벽–내부망 구조 + VPN 터널·SaaS 경로 표시
3. 3개 이상 목적지에 `ping` 10회씩 → 평균/최대 Latency·Jitter 계산
4. 동일 목적지에 `traceroute` → 구간별 지연 기록
5. 가상 SaaS 지연 시나리오의 진단 결론을 데이터 근거와 함께 작성
6. `network_zt/day05_diagram.png`, `day05_quality_report.md`로 정리

**산출물:** `network_zt/day05_diagram.png`, `network_zt/day05_quality_report.md`

## (작성 예정) 강사 예습 포인트
- 강사가 **먼저 ping·traceroute를 실측**해보고, 값 해석의 함정(한 번 튐 vs 지속 문제) 기록
- draw.io에서 DMZ/내부망을 '박스로 감싸' 경계를 분명히 그리는 예시 캡처
- "데이터 근거 → 결론" 리포트 모범 초안 (7일차 문서화와 연결)

## 평가 기준 (상세교안)
- DMZ와 내부망이 명확히 분리되어 표현되었는가
- Latency·Jitter·Packet Loss 개념을 정확히 구분해 적용했는가
- 측정 데이터에 근거해 지연 원인을 논리적으로 추정했는가
