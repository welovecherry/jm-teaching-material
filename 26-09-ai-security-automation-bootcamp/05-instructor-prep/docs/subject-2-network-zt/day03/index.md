# 2과목 Day 3 · 개요 — DNS 개념과 동작원리

!!! note "이 Day 사용법"
    왼쪽 사이드바에서 **강의1(오전) / 강의2(오후) / 실습**을 순서대로 봅니다. DNS 조회 과정과 보안 이슈는 본문 **🔬 깊이 보기**에서 단계적으로 풉니다.

> **오늘 한 문장:** 도메인 이름을 IP로 바꿔주는 **"인터넷 전화번호부(DNS)"**의 동작을 이해하고, 그것을 노린 공격과 이상징후를 식별합니다.
> **왜 배우나:** DNS는 모든 인터넷 접속의 첫 단계라, 여기가 흔들리면 전부 흔들립니다. DNS 로그 이상징후 식별은 4과목(이상탐지)로 바로 이어집니다.
