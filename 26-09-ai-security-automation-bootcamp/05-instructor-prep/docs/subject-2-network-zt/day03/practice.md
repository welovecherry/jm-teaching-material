# 실습 · DNS 조회 및 이상징후 식별 (총 120분)

!!! note "자리표시 — 뼈대만 (강사가 직접 채웁니다)"
    실습은 강사가 먼저 해보고 함정을 기록하는 성격입니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** `nslookup`/`dig`로 실제 도메인을 조회하고, DNS 로그 샘플에서 정상·비정상 패턴을 구분한다.

## 진행 단계 (상세교안 기준)
1. `nslookup`(또는 `dig`)으로 5개 이상 도메인의 A·MX 레코드 조회·기록
2. `dig +trace`로 한 도메인의 Root→Authoritative 전체 경로 확인
3. 제공된 DNS 로그 샘플(정상 + DGA 스타일 30줄) 검토
4. 무작위 문자열 패턴·비정상 짧은 TTL 등 의심 기준을 세워 이상 도메인 선별
5. 골라낸 이상 도메인 목록·근거를 `network_zt/day03_dns_analysis.md`에 정리
6. 조원과 판단 기준 비교·보완

**산출물:** `network_zt/day03_dns_analysis.md`

## (작성 예정) 강사 예습 포인트
- 강사가 **먼저 로그 샘플을 분류**해보고, 헷갈리는 경계 사례(짧지만 정상인 도메인 등) 기록
- "이 기준이면 오탐/미탐이 얼마나?" 미리 감 잡기 → 4과목 오탐·미탐 튜닝과 연결
- `dig +trace` 실제 출력 화면 캡처 자리

## 평가 기준 (상세교안)
- `nslookup`/`dig` 명령을 정확히 사용했는가
- DGA 스타일 등 의심 도메인을 합리적 근거로 식별했는가
- 판단 기준이 명확히 문서화되었는가
