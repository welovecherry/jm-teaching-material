# 실습 · 패킷 캡처·분석 (총 120분)

!!! note "자리표시 — 뼈대만 (강의1 확정 후 같은 깊이로 채웁니다)"
    실습 페이지는 "강사가 먼저 직접 해보고 함정을 기록하는" 성격입니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** Wireshark로 실제 패킷을 캡처해 3-way handshake와 IP/TCP 헤더 구조를 직접 확인합니다.

## 진행 단계 (상세교안 기준)
1. Wireshark 설치 → 자신의 네트워크 인터페이스 선택 → 캡처 시작
2. 브라우저로 특정 웹사이트 접속하며 동시에 패킷 캡처
3. 필터(`tcp.port==443` 또는 `http`)로 해당 트래픽만 걸러보기
4. SYN, SYN-ACK, ACK 3개를 찾아 캡처 화면 스크린샷
5. IP 헤더에서 출발지/목적지 IP, TTL 값 확인·기록
6. `network_zt/day01_packet_analysis.md`에 결과·관찰 정리

**산출물:** `network_zt/day01_packet_analysis.md` (캡처 스크린샷 포함)

## (작성 예정) 강사 예습 포인트
- 강사가 **먼저 직접 캡처해보고** 자주 막히는 지점(인터페이스 선택 실수, 필터 오타)을 기록
- "이렇게 나오면 성공" 예상 화면 캡처 자리
- 학생이 자주 하는 질문 미리 답변

## 평가 기준 (상세교안)
- 3-way handshake 3단계를 정확히 식별했는가
- IP 헤더 핵심 필드(출발지/목적지/TTL)를 올바르게 읽었는가
- 필터로 원하는 트래픽만 걸러냈는가
