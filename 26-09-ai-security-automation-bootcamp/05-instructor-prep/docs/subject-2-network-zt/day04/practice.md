# 실습 · 방화벽 정책 시나리오 설계 (총 120분)

!!! note "자리표시 — 뼈대만 (강사가 직접 채웁니다)"
    실습은 강사가 먼저 설계해보고 함정을 기록하는 성격입니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** 가상 기업 환경에 맞는 방화벽 룰셋을 **화이트리스트 원칙**으로 설계한다.

## 진행 단계 (상세교안 기준)
1. 가상 A사 시나리오(웹서버, DB서버, 내부 사무망, 관리자 PC) 확인
2. 각 자원별로 누가/어디서/어떤 포트로 접근해야 하는지 요구사항 정리
3. **화이트리스트 원칙**으로 룰셋 설계
4. 룰 순서(구체적 룰 먼저, 기본 차단 맨 마지막) 고려해 배치
5. `network_zt/day04_firewall_ruleset.md`에 룰셋 표 작성
6. 조원과 룰셋 검토(불필요하게 넓게 열린 규칙 없는지)

**산출물:** `network_zt/day04_firewall_ruleset.md`

## (작성 예정) 강사 예습 포인트
- 강사가 **먼저 룰셋을 설계**해보고, 학생이 자주 범하는 실수 기록
  (기본 Deny를 위에 두기 / any-any Allow로 너무 넓게 열기 / 순서 뒤바뀜)
- "이 룰은 왜 필요한가"를 한 줄씩 근거로 다는 습관 → 3과목 접근통제로 연결
- 모범 룰셋 표 + 흔한 오답 룰셋 비교 자리

## 평가 기준 (상세교안)
- 화이트리스트 원칙(최소권한)이 적용되었는가
- 룰 순서가 논리적으로 배치되었는가
- DB서버 등 민감 자원이 불필요하게 노출되지 않았는가
