# 2과목 Day 4 · 개요 — VPN 개념·종류 & 방화벽 기본

!!! note "이 Day 사용법"
    왼쪽 사이드바에서 **강의1(오전) / 강의2(오후) / 실습**을 순서대로 봅니다. VPN 종류와 방화벽 룰은 본문 **🔬 깊이 보기**에서 단계적으로 풉니다.

> **오늘 한 문장:** 안전하지 않은 인터넷 위에 **암호화 터널(VPN)**을 놓는 법과, 트래픽을 규칙으로 걸러내는 **방화벽**을 배웁니다.
> **왜 배우나:** 재택·지사 연결과 접근 통제의 핵심 도구입니다. 방화벽의 "최소권한(화이트리스트)" 사고방식은 3과목(접근통제)·6일차(Zero Trust)로 바로 이어집니다.
