# 2과목 Day 8 · 개요 — 장애·위협·접근통제 이슈 도식화 & 종합 발표

!!! note "이 Day 사용법"
    오늘은 **통합의 날**입니다. 강의(120분) 1개 + 실습(120분)으로, 1~7일차를 하나로 엮습니다. (상세교안상 강의가 하나입니다)

> **오늘 한 문장:** 7일간 배운 것을 **한 장의 지도로 정리**하고, 실제 이슈를 **플로우차트·타임라인으로 도식화**해 팀별로 발표합니다.
> **왜 배우나:** 흩어진 지식을 '연결된 하나'로 만들고, 캡스톤(ZT 보안 자세 점검·스코어링)의 착수 자료를 완성합니다.

## 이 하루에 나오는 어려운 개념 쉽게 풀기
| 용어 (한글발음) | 한 줄 뜻 (아주 쉽게) | 비유 |
|----------------|----------------------|------|
| **장애 이슈** | 연결·성능·서비스가 안 되는 문제 | 차가 안 굴러감 |
| **위협 이슈** | 공격(스푸핑·대입·SYN Flood 등) | 도둑이 침입 |
| **접근통제 이슈** | 과다권한·최소권한 위반 | 아무나 금고 접근 |
| **플로우차트** | 증상→진단→원인→조치 흐름도 | 순서도 |
| **타임라인** | 사고를 시간 순서로 정리 | 사건 일지 |

## 오늘의 최종 목표 (Day 8을 마치면)
- [ ] 1~7일차 개념을 한 장의 흐름으로 연결해 말한다
- [ ] 이슈를 장애·위협·접근통제 3유형으로 분류한다
- [ ] 이슈 대응을 플로우차트/타임라인으로 도식화한다
- [ ] 팀 시나리오를 발표하고 캡스톤 연결점을 설명한다
