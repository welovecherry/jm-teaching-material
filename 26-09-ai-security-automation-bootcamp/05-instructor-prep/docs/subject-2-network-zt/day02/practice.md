# 실습 · 망 구성도 분석 및 서브네팅 설계 (총 120분)

!!! note "자리표시 — 뼈대만 (강사가 직접 채웁니다)"
    실습은 강사가 먼저 풀어보고 함정을 기록하는 성격입니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** 주어진 기업 시나리오에 맞는 서브넷을 설계하고, 망 구성도에서 라우팅 경로를 식별한다.

## 진행 단계 (상세교안 기준)
1. 가상 A사 시나리오(본사 3개 부서, 지사 1곳, 서버실) 확인
2. 각 부서/지사 필요 호스트 수 산정 → 알맞은 서브넷(/26·/27·/28 등) 설계
3. 설계한 서브넷 표를 `network_zt/day02_subnet_design.md`에 정리
4. 제공된 망 구성도에서 라우터·스위치·VLAN 경계 표시
5. 본사 → 지사 패킷이 거치는 경로를 순서대로 기록
6. 조원과 서브넷 설계 교차 검증(겹치는 대역 없는지)

**산출물:** `network_zt/day02_subnet_design.md`

## (작성 예정) 강사 예습 포인트
- 강사가 **먼저 직접 서브넷을 설계**해보고, 학생이 자주 틀리는 계산 지점 기록
- 대역 겹침(off-by-one: .63 다음 .64) 실수 예시와 교정법
- "이 시나리오면 이렇게 나눈다" 모범 답안 표

## 평가 기준 (상세교안)
- 서브넷 계산(사용 가능 호스트 수)이 정확한가
- 부서 간 대역이 겹치지 않는가
- 망 구성도에서 라우팅 경로를 올바르게 식별했는가
