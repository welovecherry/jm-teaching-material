# 실습 · 고객 설명자료 작성 (총 120분)

!!! note "자리표시 — 뼈대만 (강사가 직접 채웁니다)"
    실습은 강사가 먼저 작성해보고 함정을 기록하는 성격입니다. 상세교안의 진행 단계만 잡아 두었습니다.

> **실습 목표:** 정책 로그 샘플을 분석해 비전문가(고객 경영진)가 이해할 수 있는 설명자료를 작성한다.

## 진행 단계 (상세교안 기준)

1. 제공된 정책 로그 샘플(30~50줄, allow/deny 혼재)을 검토해 패턴 찾기
2. 가장 중요한 이슈 1~2가지 선정
3. **결론-근거-권고** 3단 구조로 설명자료 초안 작성(전문용어 최소화)
4. 간단한 표 또는 막대그래프로 핵심 수치 시각화
5. `network_zt/day07_customer_report.md`로 저장
6. 조원과 설명자료 교환·상호 검토

**산출물:** `network_zt/day07_customer_report.md`

## (작성 예정) 강사 예습 포인트

- 강사가 **먼저 로그 샘플에서 이슈를 뽑아** 결론-근거-권고로 써보고, 전문용어를 걷어내는 과정 기록
- 전문가용 문장 → 고객용 문장 변환 예시 모음(deny→차단, posture→기기 보안 상태 등)
- "결론을 맨 앞에" 지키지 못한 나쁜 초안 vs 좋은 초안 비교

## 평가 기준 (상세교안)

- 전문용어를 비전문가도 이해할 수 있게 풀어썼는가
- 결론-근거-권고 구조를 따르는가
- 핵심 이슈가 데이터에 근거해 명확히 제시되었는가
