## 이 하루에 나오는 어려운 개념 쉽게 풀기
| 용어 (한글발음) | 한 줄 뜻 (아주 쉽게) | 비유 |
|----------------|----------------------|------|
| **정책 로그** | 누가·언제·무엇에 접근을 허용/거부했는지 기록 | 출입 기록부 |
| **필드(field)** | 로그 한 줄을 이루는 각 항목 | 표의 각 칸 |
| **action(allow/deny)** | 허용 / 거부 결정 | 통과 / 차단 도장 |
| **risk_score(리스크 스코어)** | 그 요청의 위험도 점수 | 위험 온도계 |
| **device_posture(디바이스 포스처)** | 기기 보안 상태(백신·패치 등) | 건강검진 결과 |
| **두괄식** | 결론을 맨 앞에 말하기 | 헤드라인 먼저 |
| **결론-근거-권고** | 무슨 일→데이터→할 일 3단 | 진단서 형식 |

## 오늘의 최종 목표 (Day 7을 마치면)

- [ ] 정책 로그의 주요 필드(timestamp·user·resource·action·reason·risk_score)를 읽는다
- [ ] 여러 로그를 모아 패턴(시간대·반복 거부)을 찾는다
- [ ] 전문용어를 비전문가용 표현으로 바꿔 쓴다
- [ ] 결론-근거-권고 3단 구조로 고객 설명자료를 작성한다
