## ⏱️ 00-20분 · 네트워크를 배우는 이유

??? question "Q1. 보안관제(SOC, "쏙") 담당자가 겪는 가장 흔한 상황은?"
    고객은 **증상만** 말합니다("접속이 안 돼요", "느려요"). **원인은 우리가** 찾아야 합니다. 그래서 통신 과정을 단계로 쪼개 볼 줄 알아야 원인을 좁힐 수 있습니다.

??? question "Q2. 통신을 '계층으로 나눠' 보면 뭐가 좋은가?"
    "여기까지는 정상, 여기서 막혔다"라고 **범위를 좁힐 수 있습니다.** 지도 없이 아무 데나 찔러보는 것보다 훨씬 빠릅니다.

??? question "Q3. 이 2과목이 왜 중요한가? (뒤 과목과의 관계)"
    3·4·5과목(접근통제·이상탐지·SOAR)이 전부 **네트워크 지식 위에** 얹혀 있습니다. 지금 기초를 다지면 남은 과목이 쉬워집니다.

!!! question "확인질문 · 나의 답"
    **Q. '인터넷이 느려요'만 들었을 때 어느 계층부터 확인할까?**
    A. 아래→위 순서로: 케이블·연결(1계층) → IP·핑(3계층) → 서비스 포트(4계층). 아래부터 하나씩 지워 범위를 좁힙니다.

## ⏱️ 20-50분 · 1·2·3계층

??? question "Q4. OSI(오에스아이) 7계층이란 한마디로?"
    통신 과정을 **7층 건물처럼 나눈 지도**입니다. 아래 3칸은 "데이터를 목적지까지 나르는" 부분입니다.

??? question "Q5. 1계층(물리)은 무엇을 다루나?"
    전기 신호가 흐르는 **케이블·허브** 등. 편지로 치면 **도로 그 자체**입니다. "0과 1이 전선을 탄다"까지.

??? question "Q6. 2계층(데이터링크)의 주소와 장비는?"
    **MAC(맥) 주소** — 기기마다 공장에서 찍혀 나오는 고유번호. 장비는 **스위치**. **같은 네트워크(동네) 안**에서 전달합니다.

??? question "Q7. 3계층(네트워크)의 주소와 장비는?"
    **IP(아이피) 주소** — 접속 위치에 따라 바뀌는 주소. 장비는 **라우터**. **다른 네트워크 간** 전달을 담당합니다.

??? question "Q8. MAC과 IP를 비유로 구분하면?"
    **MAC = 주민등록번호**(기기에 평생 고정), **IP = 사는 집 주소**(바뀜). 같은 동네는 이름표(MAC)로 찾고, 먼 도시는 도로명 주소(IP)가 필요합니다.

!!! tip "실무 팁"
    **핑(ping)이 된다 = 3계층까지 살아 있다.** 문제를 만나면 핑부터 → "네트워크 문제냐, 그 위 문제냐"의 첫 갈림길.

!!! question "확인질문 · 나의 답"
    **Q. 같은 사무실 두 PC vs 인터넷 너머 서버, 주소 체계가 다른 이유?**
    A. 같은 네트워크 안은 **MAC(2계층)**으로 바로 찾고, 다른 네트워크로 가려면 **IP(3계층)**로 라우터가 길을 잡아야 하기 때문입니다.

## ⏱️ 50-80분 · 4·5·6·7계층

??? question "Q9. 위 4칸(4~7계층)은 아래 3칸과 뭐가 다른가?"
    아래 3칸은 "목적지 **기기까지** 배달", 위 4칸은 "그 기기 **안에서** 올바른 프로그램에 전달하고 사람이 쓸 형태로 만듦".

??? question "Q10. 4계층(전송)의 핵심 개념은?"
    **포트(port) 번호**. IP가 "건물 주소"면 포트는 "몇 호실". 목적지 컴퓨터 안 여러 프로그램 중 어디로 갈지 구분합니다.

??? question "Q11. TCP와 UDP의 차이는?"
    **TCP(티씨피)** = 등기우편(확인하며 확실히, 신뢰성↑, 웹·파일전송). **UDP(유디피)** = 일반우편(확인 없이 빠르게, 속도↑, 스트리밍·DNS질의).

??? question "Q12. 5·6계층(세션·표현)은?"
    연결을 관리(세션)하고 데이터를 암호화·인코딩(표현)합니다. 실무 비중이 낮아 오늘은 "이런 역할" 정도만.

??? question "Q13. 7계층(응용)에는 무엇이 사는가?"
    사람이 쓰는 서비스층 — **HTTP(웹)·SMTP(메일)·DNS(이름풀이)** 등.

??? question "Q14. 자주 쓰는 포트 4개는? (외우기)"
    `80` HTTP(웹) · `443` HTTPS(암호화 웹) · `22` SSH(원격 접속) · `53` DNS(도메인→IP).

!!! tip "실무 팁"
    방화벽 로그에 `dst port 22` 급증 → SSH 접속 시도. 포트를 알면 로그가 읽힙니다. (→ 4과목 이상탐지 연결)

!!! question "확인질문 · 나의 답"
    **Q. 같은 IP 서버에서 웹과 이메일을 동시에 운영할 수 있는 이유?**
    A. **포트 번호(4계층)** 덕분입니다. IP는 같아도 웹은 `443`, 메일은 별도 포트로 들어와 서버가 구분해 각 프로그램에 전달합니다. (건물 주소는 하나, 호실은 여러 개)
