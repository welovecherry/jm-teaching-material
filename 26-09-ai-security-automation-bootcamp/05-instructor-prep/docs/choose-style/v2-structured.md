# 【버전 B · 구조화 요약형】 2과목 Day1 · OSI 7계층 (강의1 앞 1시간)

!!! note "이 문서는 스타일 비교용 샘플입니다"
    같은 내용을 A/B/C 세 가지 스타일로 만든 것 중 **B안**입니다. 표·목록·상자 중심으로 **한눈에 스캔**하게 썼습니다.

> **오늘 한 문장:** 통신을 7층으로 나눈 지도(OSI 7계층)로 "어디가 막혔는지" 짚는다.
> **왜 배우나:** ① 장애 원인을 계층별로 좁혀 답한다 ② 3·4·5과목의 공통 기반이 된다.

## ⏱️ 00-20분 · 네트워크를 배우는 이유

**📖 교안 요지**

- 보안관제(SOC, "쏙")는 고객의 증상("안 돼요")만 듣고 **원인은 직접** 찾아야 함
- 통신을 계층으로 쪼개 보면 "여기까지 정상 / 여기서 막힘"으로 **범위 축소** 가능
- 2과목(네트워크·ZT)은 3·4·5과목(접근통제·이상탐지·SOAR)의 **공통 배경지식**

**🧠 쉽게 이해하기**

- 지도 없이 문제를 만나면 → 아무 데나 찔러봄(비효율)
- 계층 지도가 있으면 → 아래층부터 순서대로 지워가며 원인 위치 특정

!!! question "확인질문 · 나의 답"
    **Q. '인터넷이 느려요'만 들었을 때 어느 계층부터 확인?**
    A. 아래→위 순서. 케이블·연결(1) → IP·핑(3) → 서비스 포트(4). 아래부터 지워 범위를 좁힌다.

---

## ⏱️ 20-50분 · 1·2·3계층 (데이터를 "나르는" 부분)

| 계층 | 이름 | 주소/식별 | 대표 장비 | 역할 한 줄 |
|:---:|------|-----------|-----------|-----------|
| **1** | 물리 Physical | 전기신호 | 케이블·허브 | 신호를 전선으로 흘려보냄 |
| **2** | 데이터링크 Data Link | **MAC 주소** | 스위치 | **같은 네트워크 안** 전달 |
| **3** | 네트워크 Network | **IP 주소** | 라우터 | **다른 네트워크 간** 전달 |

**🔑 MAC vs IP (가장 중요한 비교)**

| | MAC(맥) 주소 | IP(아이피) 주소 |
|---|---|---|
| 비유 | 주민등록번호(평생 고정) | 사는 집 주소(바뀜) |
| 범위 | 같은 동네(네트워크) 안 | 동네 밖(네트워크 간) |
| 계층 | 2계층 | 3계층 |

!!! tip "실무 팁"
    **핑(ping)이 된다 = 3계층까지 살아 있다.** 그래서 문제를 만나면 핑부터 확인 → "네트워크 문제냐, 그 위 문제냐"의 첫 갈림길.

!!! question "확인질문 · 나의 답"
    **Q. 같은 사무실 두 PC vs 인터넷 너머 서버, 주소 체계가 다른 이유?**
    A. 같은 네트워크 안은 **MAC(2계층)**으로 바로 찾음. 다른 네트워크로 가려면 **IP(3계층)**로 라우터가 길을 잡아야 함.

## ⏱️ 50-80분 · 4·5·6·7계층 (기기 "안"에서 전달)

| 계층 | 이름 | 핵심 | 예시 |
|:---:|------|------|------|
| **4** | 전송 Transport | **포트 번호** / TCP·UDP | 어느 프로그램으로 갈지 구분 |
| **5·6** | 세션·표현 | 연결 관리 / 암호화·인코딩 | (오늘은 개념만) |
| **7** | 응용 Application | 사람이 쓰는 서비스 | HTTP·DNS·SMTP |

**🔑 TCP vs UDP**

| | TCP(티씨피) | UDP(유디피) |
|---|---|---|
| 비유 | 등기우편(확인함) | 일반우편(빠름) |
| 특징 | 신뢰성 ↑ | 속도 ↑ |
| 예 | 웹·파일전송 | 스트리밍·DNS질의 |

**📌 자주 쓰는 포트 (암기 권장)**

| 포트 | 서비스 | 뜻 |
|:---:|--------|-----|
| `80` | HTTP | 일반 웹 |
| `443` | HTTPS | 암호화 웹(자물쇠) |
| `22` | SSH | 서버 원격 접속 |
| `53` | DNS | 도메인 → IP 변환 |

> 💡 **포트 = 건물(IP) 안 몇 호실.** IP가 같아도 포트로 서비스를 구분한다.

!!! tip "실무 팁"
    방화벽 로그의 `dst port 22`가 급증 → SSH 접속 시도. 포트를 알면 로그가 읽힌다. (→ 4과목 이상탐지 연결)

!!! question "확인질문 · 나의 답"
    **Q. 같은 IP 서버에서 웹과 이메일을 동시에 운영할 수 있는 이유?**
    A. **포트 번호(4계층)** 덕분. IP는 같아도 웹은 `443`, 메일은 별도 포트 → 서버가 구분해 각 프로그램에 전달.
