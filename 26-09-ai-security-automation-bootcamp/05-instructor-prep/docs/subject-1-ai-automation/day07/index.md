# 1과목 Day 7 · 개요 — LLM 활용(이벤트 요약·프롬프트 체이닝) & 보고서 자동 생성

!!! note "이 Day 사용법 (강사 예습)"
    Day 7은 Day 6의 LLM을 **실무 파이프라인**으로 키웁니다. 수백 건 이벤트를 **배치로 요약**하고, 여러 단계로 나눠 부르는 **프롬프트 체이닝**을 배우며, **템플릿+LLM**으로 매번 같은 형식의 보고서를 자동 생성합니다. 여전히 **🐍 문법 상자**로 새 문법(제너레이터·정렬·`.format`)을 정리합니다.

> **오늘 한 문장:** 많은 이벤트를 **청크 단위**로 나눠 요약하고, `risk_order`로 우선순위를 **정렬**하며, 긴 작업을 **프롬프트 체이닝**으로 쪼개 안정화하고, **고정 템플릿에 LLM 문장만** 채워 일관된 보고서를 만듭니다.
> **왜 배우나:** 이 `event_summarizer.py`가 4과목이 재사용한 바로 그 요약 모듈입니다. 배치·정렬·체이닝·템플릿 결합은 실제 자동화 리포트의 핵심 패턴이고, Day8 전체 통합의 재료가 됩니다.

## 오늘의 최종 목표 (Day 7을 마치면)
- [ ] AI 요약에도 사람 최종 판단(Human-in-the-loop)이 필요함을 안다
- [ ] `chunk_list`(제너레이터)로 많은 입력을 배치 처리한다
- [ ] `risk_order` 매핑과 `sorted(key=...)`로 우선순위 정렬한다
- [ ] 프롬프트 체이닝(단계 분할)의 이점을 안다
- [ ] 중간 결과를 로깅·저장해 단계별로 추적한다
- [ ] `.format` 템플릿에 데이터를 채워 보고서 뼈대를 만든다
- [ ] 상세 문단만 LLM에 위임하고, 조건부 경고를 삽입한다
