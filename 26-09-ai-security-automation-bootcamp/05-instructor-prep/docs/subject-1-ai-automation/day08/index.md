# 1과목 Day 8 · 개요 — 파이프라인 통합·알림연동 & 전체 리뷰·발표

!!! note "이 Day 사용법 (강사 예습)"
    Day 8은 1~7일차의 조각을 **하나의 파이프라인**으로 통합하고, **이메일·메신저 알림**을 붙이며, **설정을 config.yaml 하나로** 모으고, 코드 리뷰·디버깅으로 마무리합니다. 완성된 `agent_core/`가 2~5과목과 캡스톤의 기반이 됩니다.

> **오늘 한 문장:** **입력→분류→요약→알림→리포팅**을 `run_pipeline()`으로 오케스트레이션하고, `smtplib`·메신저 Webhook으로 알림을 보내며(실패 fallback 포함), 흩어진 설정을 **config.yaml**로 모아 어떤 고객사에도 재사용 가능한 완성본을 만듭니다.
> **왜 배우나:** 오늘 완성하는 `agent_core/`는 2~5과목 모듈이 꽂히고 캡스톤의 최종 보안 Agent가 되는 뼈대입니다. 통합·알림·config 분리는 실무 자동화의 마지막 완성 단계입니다.

## 오늘의 최종 목표 (Day 8을 마치면)
- [ ] 1~7일차 기능을 입력→분류→요약→알림→리포팅으로 통합한다
- [ ] `smtplib`로 이메일을 보낸다(비밀번호는 환경변수)
- [ ] 메신저 Webhook 알림과 실패 fallback을 구현한다
- [ ] 흩어진 설정을 `config.yaml` 하나로 모은다
- [ ] `run_pipeline()`으로 단계별 try/except 오케스트레이션을 한다
- [ ] 코드 리뷰 체크리스트로 자기 코드를 점검한다
- [ ] traceback을 읽어 디버깅하고, 캡스톤 연결점을 설명한다
