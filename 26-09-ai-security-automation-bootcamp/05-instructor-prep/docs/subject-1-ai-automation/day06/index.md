# 1과목 Day 6 · 개요 — LLM 개념·프롬프트 엔지니어링 & AI Agent Tool-use 구조

!!! note "이 Day 사용법 (강사 예습)"
    Day 6부터 **AI**를 붙입니다. **LLM(거대언어모델)** 이 무엇인지, 좋은 **프롬프트**를 어떻게 쓰는지, 그리고 LLM이 **스스로 도구(함수)를 선택해 호출**하는 **AI Agent** 구조를 배웁니다. LLM API 호출은 Day4 requests를 그대로 쓰고, 도구 라우터는 3·4과목의 registry 패턴과 이어집니다.

> **오늘 한 문장:** LLM이 "다음 단어를 확률로 생성"하는 원리(환각 주의)를 이해하고, **역할·지시·형식·예시** 4원칙으로 프롬프트를 설계하며, LLM 응답을 안전하게 파싱해 **tool_registry로 함수를 라우팅**하는 미니 에이전트의 뼈대를 만듭니다.
> **왜 배우나:** 캡스톤의 자동 회수봇·초동대응봇이 모두 이 AI Agent 구조 위에서 돕니다. 오늘 만든 `tool_router`가 3·4과목에서 `tool_registry`로 재등장한 바로 그 엔진입니다.

## 오늘의 최종 목표 (Day 6을 마치면)
- [ ] LLM이 '생성'이라 환각 가능성이 있고 사람 검증이 필요함을 안다
- [ ] 프롬프트 4원칙(역할·지시·형식·예시)으로 프롬프트를 쓴다
- [ ] LLM API를 requests로 호출하고 temperature의 의미를 안다
- [ ] LLM의 JSON 응답을 방어적으로 파싱한다
- [ ] 챗봇과 AI Agent의 차이를 안다
- [ ] Tool-use 구조(LLM은 선택, 실행은 우리 코드)를 이해한다
- [ ] tool_registry로 도구를 라우팅하고 승인 게이트 개념을 안다
