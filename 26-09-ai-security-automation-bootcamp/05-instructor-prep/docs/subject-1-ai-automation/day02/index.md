# 1과목 Day 2 · 개요 — 함수·모듈화 & 파일 입출력·예외처리·로깅

!!! note "이 Day 사용법 (강사 예습)"
    Day 1이 "값·조건·반복"이었다면, Day 2는 코드를 **함수로 묶어 재사용**하고, **파일을 읽고 쓰며**, 에러가 나도 **죽지 않는(예외처리)** 안전한 코드를 만듭니다. 여전히 **🐍 문법 상자**로 문법을 하나씩 정리하고, 영어 코드 + 한국어 주석을 씁니다.

> **오늘 한 문장:** 반복되는 코드를 **함수**로 묶고 **모듈(파일)** 로 나누며, **파일 입출력**으로 실제 로그 파일을 다루고, **try/except**와 **logging**으로 "오류가 나도 멈추지 않고 기록을 남기는" 파서를 만듭니다.
> **왜 배우나:** 자동화는 "사람이 안 봐도 돌아가는 코드"입니다. 그러려면 오류가 나도 죽지 않고(예외처리), 무슨 일이 있었는지 남겨야(로깅) 합니다. 오늘 만든 안전한 파서가 2~4과목 데이터 처리의 기본기입니다.

## 오늘의 최종 목표 (Day 2를 마치면)
- [ ] `def`로 함수를 정의하고 `return`으로 결과를 돌려준다
- [ ] 매개변수 기본값의 의미를 안다
- [ ] 함수를 `utils.py` 모듈로 분리해 `import`한다
- [ ] `datetime`으로 타임스탬프를 파싱한다
- [ ] `with open()`으로 파일을 안전하게 읽고, `csv.DictReader`로 CSV를 다룬다
- [ ] `try/except`로 구체적 예외를 잡는다
- [ ] `logging`과 `RotatingFileHandler`로 처리 현황을 기록한다
