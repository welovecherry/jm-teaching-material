# 1과목 Day 1 · 개요 — 개발환경 구축 & 파이썬 기초(변수·자료형·제어문)

!!! note "이 Day 사용법 (강사 예습)"
    1과목은 **파이썬 그 자체**를 배우는 과목입니다. 그래서 이 예습 노트는 문법 하나하나를 **🐍 문법 상자**로 따로 정리하고, **가장 쉬운 코드부터 다양한 예제**로 반복합니다. 코드는 영어로, 주석은 한국어로 씁니다. 왼쪽 사이드바에서 강의1(오전)/강의2(오후)/실습 순서로 보세요.

!!! tip "📌 이 노트의 약속"
    - **🐍 문법 상자** = "이 문법은 이렇게 읽고, 이렇게 쓰고, 이런 실수를 조심한다"를 따로 정리한 칸
    - **💻 코드 조각** = 3~6줄짜리 아주 짧은 예제. 직접 쳐서 돌려보세요
    - **✍️ 직접 쳐보기** = 강의 중 학생에게 줄 손코딩 미션
    - 모든 코드: **영어 코드 + 한국어 주석**. 변수명은 의미가 드러나게(`failed_count` 등)

> **오늘 한 문장:** 파이썬을 처음 켜고, **변수에 값을 담고**, **자료형(숫자·글자·참거짓)** 을 구분하고, **조건문·반복문**으로 로그를 걸러내는 것까지 — 프로그래밍의 가장 기본 뼈대를 익힙니다.
> **왜 배우나:** 앞으로 8일(그리고 2~4과목 전체)에서 쓸 모든 코드가 오늘 배우는 변수·자료형·제어문 위에 쌓입니다. 여기가 흔들리면 뒤가 다 흔들립니다.

## 오늘의 최종 목표 (Day 1을 마치면)
- [ ] 가상환경(venv)을 만들고 프로젝트 폴더 구조를 이해한다
- [ ] 변수에 값을 담고, `type()`으로 자료형(int/float/str/bool)을 확인한다
- [ ] f-string으로 값이 섞인 문자열을 만든다
- [ ] 리스트·딕셔너리를 만들고 값을 꺼낸다(`[]` vs `.get()`)
- [ ] `str()/int()/float()` 형변환과 흔한 에러를 안다
- [ ] `if/elif/else`, `for/while`, `enumerate`로 로그를 걸러낸다
- [ ] 리스트 컴프리헨션, `set`, `Counter`로 집계한다
