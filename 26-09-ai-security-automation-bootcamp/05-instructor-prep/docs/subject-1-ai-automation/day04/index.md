# 1과목 Day 4 · 개요 — API·HTTP·requests 실전 & 인증정보 관리

!!! note "이 Day 사용법 (강사 예습)"
    Day 4는 내 프로그램을 **바깥 세상(다른 서버)** 과 연결합니다. **API**로 데이터를 주고받는 원리(HTTP·상태코드)를 배우고, **requests** 라이브러리로 실제 호출하며, **API 키**를 안전하게 관리하는 법을 익힙니다. 여전히 **🐍 문법 상자**로 하나씩 정리합니다.

> **오늘 한 문장:** **API**가 무엇인지(식당 메뉴판 비유), **HTTP 메서드·상태코드**로 요청/응답을 읽는 법, **requests**로 GET·POST를 보내고 실패 시 **재시도**하는 법, 그리고 **API 키를 코드에 안 박고 `.env`로** 관리하는 법을 배웁니다.
> **왜 배우나:** 자동화의 절반은 "다른 시스템과 연결"입니다. SIEM·티켓시스템·LLM 모두 API로 부릅니다. 오늘 배우는 requests·재시도·인증 관리가 4과목 탐지 연동, 6~8과목 LLM 호출의 기반입니다.

## 오늘의 최종 목표 (Day 4를 마치면)
- [ ] API를 "메뉴판과 주방" 비유로 설명한다
- [ ] HTTP 메서드(GET/POST/PUT/DELETE)와 URL 구조를 안다
- [ ] 상태코드(200/201/400/401/403/404/429/500)를 읽는다
- [ ] API 키를 `.env`로 분리하고 `.gitignore`에 넣는 이유를 안다
- [ ] `requests.get/post`로 호출하고 `.json()`으로 응답을 읽는다
- [ ] `params`·`headers`를 딕셔너리로 안전하게 넘긴다
- [ ] `try/except`와 최대 횟수 제한이 있는 재시도 패턴을 구현한다
