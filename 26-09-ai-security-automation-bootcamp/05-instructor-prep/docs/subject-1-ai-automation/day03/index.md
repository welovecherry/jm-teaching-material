# 1과목 Day 3 · 개요 — 자료구조 심화 & JSON·정규표현식

!!! note "이 Day 사용법 (강사 예습)"
    Day 3은 **데이터를 다루는 힘**을 키웁니다. 중첩된 자료구조를 파고들고, **JSON**으로 데이터를 저장·교환하며, **정규표현식**으로 지저분한 텍스트에서 원하는 값만 뽑아냅니다. 정규표현식은 특히 헷갈리므로 **🐍 문법 상자**로 기호 하나하나를 뜯어봅니다.

> **오늘 한 문장:** 리스트·딕셔너리가 **겹쳐진 구조**를 자유롭게 파고들고, **JSON**으로 데이터를 파일에 저장·교환하며, **정규표현식**으로 raw 텍스트 로그에서 시간·사용자·IP를 뽑아 구조화합니다.
> **왜 배우나:** 실제 로그·API 데이터는 겹겹이 중첩된 JSON으로 오고, 방화벽 로그처럼 정형화 안 된 텍스트도 많습니다. 오늘 배우는 JSON·정규표현식이 2~4과목의 "데이터를 정형으로 바꾸는" 작업의 핵심 도구입니다.

## 오늘의 최종 목표 (Day 3을 마치면)
- [ ] 중첩 딕셔너리·리스트를 대괄호 체이닝으로 파고든다
- [ ] `in` 연산자로 값 포함 여부를 확인한다
- [ ] JSON과 파이썬 표기 차이(true/True 등)를 안다
- [ ] `json.dump/load`로 저장·읽기(`indent`, `ensure_ascii=False`)를 한다
- [ ] 필수 필드 누락을 체크하는 패턴을 쓴다
- [ ] 정규표현식 기본 기호(`\d \w . * + ? ()`)를 읽는다
- [ ] named group과 `groupdict()`로 여러 값을 한 번에 추출한다
