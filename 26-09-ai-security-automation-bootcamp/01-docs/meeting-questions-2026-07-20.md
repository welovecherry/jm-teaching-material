## A. 반드시 답을 받아야 할 것

### A-1. 계약 (제일 먼저)
1. 계약서는 **언제** 쓰나요? (착수 전 / 첫 강의일 / 사후)
   → 계약서 서명 전에 제작한 교안의 대가는 어떻게 정산되나요?
2. 계약 형태는? (프리랜서 용역 / 전임강사 위촉 / 시간강사)
   - 원천징수 3.3% vs 4대보험, 사업소득 vs 근로소득
3. **보수 산정 기준**: 강의 시간당인가요, 일당인가요, 과정 총액인가요?
   - 교안 제작 시간은 별도 산정인가요, 강의료에 포함인가요?
4. **지급 시기**: 월 단위 정산? 과목 종료 시? 과정 전체 종료 후?
5. 중도 취소·과정 축소·수강생 미달 시 보수는 어떻게 되나요? (최소 보장분)
6. 리추얼(아침 1h + 마무리 1h)도 **근무·보수 시간에 포함**되나요?
   → 하루 8시간 중 순수 교육은 6시간입니다.

### A-2. 교안 제작 범위 — "어디까지 내가 만드나"
7. **PPT를 제가 새로 만들어야 하나요?**
   - `02-source/`에 시냅스 SKT K-뉴딜 과정의 상세교안(.docx)·슬라이드(.pptx)가 있습니다.
     이걸 **그대로 써도 되나요**, 아니면 제 스타일로 재제작해야 하나요?
   - 재제작이면 그건 별도 제작비 대상인가요?
8. 제출해야 하는 **필수 산출물 목록**은? (PPT / 실습 노트북 / 교재 PDF /
   주차별 계획서 / 평가지 / 출결부 / 강의계획서 양식)
9. **양식·템플릿**이 정해져 있나요? (기관 로고, 표지 규격, 폰트)
10. **제출 마감일**은 언제인가요? 과목 시작 며칠 전까지?
11. 검수·승인 절차가 있나요? 누가 검토하고, 수정 요구는 몇 회까지인가요?

### A-3. 저작권·소유권
12. 제작한 교안의 **저작권은 누구에게** 귀속되나요? (강사 / 기관 / 공동)
13. 이 교안을 **다른 강의에 재사용**해도 되나요?
14. 반대로 `02-source/`의 기존 교안을 제 다른 강의에 쓸 수 있나요?
15. 강의 **녹화**를 하나요? 녹화본의 사용 범위·기간은?

### A-4. 확정 안 된 사실관계 (리포에 ⚠️로 남아있음)
16. **과정 정확한 시작일**과 전체 일정표 (현재 `start_date: 2026-09-01`은 추정)
17. P1-1 → P1-2 → P2-1 …이 **연속인가 중간에 공백**이 있나요? 총 40.5일의 달력 배치는?
18. **P3 캡스톤에서 SKT 현직자 멘토링**이 실제로 병행되나요?
    (원본 스캔이 가려져 확인 불가) 병행이면 제 역할과 멘토 역할의 경계는?
19. **실습(15–17시)의 성격**: 운영 카드는 "개인 창작(자기 프로젝트)",
    상세교안은 "제어문 기반 로그 필터링 스크립트"로 서로 다릅니다.
    → **고정 과제**인가요, **자유 창작**인가요? (노트북 설계가 완전히 달라집니다)
