## 스타일 요구사항 (확정)
- 언어: 한국어, **최대한 쉬운 말투 · 자세하게 · 가독성 우선**
- 구조: **A(강의 흐름) + C(워크북) 혼합**. 섹션마다 5박자 반복 —
  `📌개념 → 💻따라치기 → ✍️직접 바꿔보기(TODO) → 📝메모 → ❓확인질문`
- 앞부분: 🪧표지 · 📑목차 · 🎯학습목표 · 📦오늘의 산출물 · 📖용어풀이 · 🕹️사용법
- 마무리: 🎯요약 · 🧩퀴즈(정답 접기) · ⏭️다음 예고
- **코드/명령 규칙**: 한 줄씩 주석으로 빠짐없이 설명 / 셀은 하나씩 실행(길게 잇지 않기) /
  각 실행 뒤 **"✅ 이렇게 나오면 성공"** 예상 결과 명시 (실제 실행으로 검증)
- 개념·자료형 4종·f-string 등은 **보안 로그** 소재로 예시 (뒤 과목과 연결)
