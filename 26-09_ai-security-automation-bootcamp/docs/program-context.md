## 정제 요약

- **하루 운영(8h)**: 아침 리추얼 1h → 강의1 2h → (점심) → 강의2 2h → 실습 2h → 마무리 리추얼 1h.
  순수 교육 6h. 리추얼(앞뒤 각 1h)은 교안 바깥 운영 요소.
- **전임강사 담당 커리큘럼**: P1-1(8일)·P1-2(7.5일)·P2-1(5일)·P2-2(5일)·P2-3(5일)·P3 캡스톤(10일).
- **연결**: 우리가 작업 중인 "1과목 AI자동화기초" = **P1-1**, 그중 **Day 1**.
- ⚠️ 확인 필요: P3 행 "SKT 현직[자 멘토]링과 병행" — 스캔 가려짐, 원문 확인 요망.

### 강사 메모 (원본)
1. 하루 실제 구조가 8시간. 앞뒤 리추얼(1h+1h) 포함, 순수 교육은 강의1(2h)+강의2(2h)+실습(2h)=6h.
   Day 1 시간 블록(강의1/강의2/실습)은 그대로 유효, 리추얼은 교안 바깥 운영 요소.
2. 실습 성격 차이: 운영 카드 실습 = "개인 창작(자기 프로젝트)", 원본 상세교안 Day 1 실습 =
   "제어문 기반 로그 필터링 스크립트"로 더 구체적. 노트북 제작 시 고정 과제 vs 자유 창작 조율 필요.
