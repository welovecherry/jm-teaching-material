# 강의 정보 — AI·보안 자동화 부트캠프

## 개요 (정제 요약)
전임강사가 담당하는 부트캠프 전체 과정. 하루 **8시간** 운영:
아침 리추얼(1h) + 강의1(2h) + 강의2(2h) + 실습(2h) + 마무리 리추얼(1h).
→ 순수 교육 6h(강의 4h + 실습 2h), 앞뒤 리추얼은 교안 바깥 운영 요소.

## 담당 커리큘럼 (과목별)
| 과목 | 기간 | 핵심 |
|------|------|------|
| **P1-1 AI·자동화 기초** | 8일 | Python 기초, requests/JSON·공개 API, LLM API 호출·프롬프트, Discord Webhook, 바이브 코딩, 자동화 파이프라인 |
| P1-2 네트워크·ZT 기초 | 7.5일 | (코딩 없음) TCP/IP·DNS·HTTP(S), 방화벽·VPN, 품질지표, Zero Trust, 최소권한, 제안 화법 |
| P2-1 접근통제 자동화 | 5일 | IAM·RBAC, 과다권한 탐지, 승인·증적, 안전한 회수 — Python 구현 |
| P2-2 이상탐지 자동화 | 5일 | 로그·이벤트 분석, 룰 기반 탐지, 오탐/미탐, LLM 트리아지 |
| P2-3 자동 대응(SOAR) | 5일 | 플레이북, 차단·티켓·에스컬레이션 자동화, 승인 게이트 |
| P3 캡스톤 운영 | 10일 | 팀별 보안 봇 제작 코칭, 코드 리뷰, 발표 지도 |

> 상단 표는 정제 요약이며, **무손질 원본은 [`program-context.md`](./program-context.md)** 참조.
> 일자별 상세교안은 `syllabus.md`에 축적한다.

## 현재 작업 상태
- **P1-1 AI·자동화 기초 → Day 1** 실습 노트북 제작이 진행 중이었음(다른 세션).
- ⚠️ **Day 1 상세교안 원본 / 정리한 Day 1 흐름은 아직 이 리포에 없음** → 강사 제공 필요.

  "제어문 기반 로그 필터링 스크립트" — 노트북 제작 시 고정 과제/자유 창작 여부 결정.
